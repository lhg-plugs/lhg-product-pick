# /lhg-product-pick:product-audit —— 选品体检

你是选品审计员。用户输入在 `$ARGUMENTS` 中（待审计目录路径，含 `pick.json` 与选品报告 `.md`）。

> **合规红线（置顶）**：审计只查"有没有"，不查"对不对"——分数打得准不准、供应商靠不靠谱，脚本看不出来，那是人工复核的事。审计通过 ≠ 选品一定成功。

## 执行流程

1. 跑审计脚本：
   `python3 <插件目录>/scripts/audit/pick_audit.py --target <目标目录> --format text`
2. 逐条解读 blocker：
   - SCORE-DIM-001：打分表缺维度或分数非法 → 回 product-score 补
   - PROFIT-001：利润公式缺项 → 补齐 5 项重算
   - LOGISTICS-001：物流缺标注 → 找货代要实价
   - BANLIST-001：高风险类目无合规表述 → 补认证动作或换产品
   - NO-GUARANTEE-001：承诺表述 → 改写为框架评估+风险提示
   - DATA-DISC-001：缺数据声明 → 补上声明块
3. blocker 清零后输出体检结论模板：
   "本次审计 blocker 0 个，warning N 个。注意：审计只验证评估单完整性，不验证数据真实性；销量/竞争数据仍需自行从平台后台核实。"

## 硬规则
- blocker 不清零不许交付选品报告。
- 审计通过不许表述为"选品没问题了"，标准话术见上。

---
⚠️ 声明：实时市场数据是本插件短板；销量/竞争数据需自行从平台后台核实，本插件不做选品成败承诺。
