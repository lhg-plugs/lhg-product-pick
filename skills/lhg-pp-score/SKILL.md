# lhg-pp-score：五维选品打分表

> ⚠️ **声明（先读）**：**实时市场数据是本插件短板**。打分依据的销量/竞争数字必须来自用户**自行从平台后台核实**的数据；分数是"基于已知信息的评估"，不是"预测结果"。本插件**不做选品成败承诺**。
>
> 目标：把"我觉得这个能卖"变成 5 个维度的分数。核心纪律：**先打分后结论，缺维度不许出报告**。

## 1. 何时使用

- 用户给出候选产品（1 个或多个）→ 全流程打分
- 用户拿着平台后台数据回来 → 把数字填进评分依据
- 多个候选做横向对比 → 同一张表打完再排优先级

## 2. 输入输出

| 输入 | 输出 |
|---|---|
| 候选产品名 + 目标市场（lhg-pp-market 结论） | `pick.json`（5 维分数+利润测算+物流标注） |
| 用户核实的 6 项数据（可选，有则更准） | 加权总分 + Go/Caution/No-Go 结论 |
| — | 选品评估报告（.md，审计脚本可检） |

## 3. 五维定义与评分标尺

每维 1~5 分，5 最优。**竞争烈度是反向维度**：竞争越小分数越高（见标尺）。

### 维度一：市场需求（权重 25%）

| 分数 | 标尺 |
|---|---|
| 5 | 目标关键词搜索趋势 90 天持续上升，且有明确使用场景 |
| 4 | 需求稳定，类目常年有量（常青类目） |
| 3 | 需求存在但季节性强（只旺 2~3 个月） |
| 2 | 需求靠营销创造（没人搜，全靠内容种草） |
| 1 | 伪需求：只是"我觉得有用"，无搜索无讨论 |

### 维度二：竞争烈度（权重 20%，反向：竞争越小分越高）

| 分数 | 标尺 |
|---|---|
| 5 | Top 10 竞品评价数普遍 <500，有明显差评痛点可切入 |
| 4 | 有头部但存在价格带空白或功能空白 |
| 3 | 竞争充分，靠差异化能挤进去 |
| 2 | 头部垄断（Top 3 占 70%+ 评价），新品难露头 |
| 1 | 红海：价格战已打到成本线 |

### 维度三：利润空间（权重 25%）

按完整公式测算后再打分（公式见第 4 步）：

| 分数 | 标尺（毛利率=单件毛利/售价） |
|---|---|
| 5 | ≥40% |
| 4 | 30%~40% |
| 3 | 20%~30% |
| 2 | 10%~20% |
| 1 | <10%（一单退货就亏） |

**铁律**：毛利率 <20% 的新手单直接判 No-Go，不许"走量补回来"。

### 维度四：物流适配（权重 15%）

| 分数 | 标尺 |
|---|---|
| 5 | 小件轻抛（<500g），空运也划算，配送 <15 天 |
| 4 | 可海运，头程时效 20~30 天，体积可控 |
| 3 | 大件或重货，物流成本占售价 >25% |
| 2 | 易碎/液体/带电，特殊渠道+高运费 |
| 1 | 超大件、需海外仓前置备货，新手玩不起 |

### 维度五：合规风险（权重 15%，反向：风险越小分越高）

| 分数 | 标尺 |
|---|---|
| 5 | 普通日用品，无认证要求 |
| 4 | 需基础材质证明，供应商可提供 |
| 3 | 需 CE/FCC 等认证，周期 1~2 个月 |
| 2 | 儿童/食品接触/化妆品类，认证严、周期长 |
| 1 | 禁售或强监管类目（医疗器械宣称、电子烟等） |

**红线**：合规风险 =1 的产品，无论总分多高，直接 No-Go。

## 4. 利润测算公式（完整版）

```
单件毛利 = 售价 − 采购成本 − 平台佣金 − 物流成本 − 退货损耗
毛利率   = 单件毛利 / 售价
```

五项缺一不可（审计脚本 PROFIT-001 会查）：
- 售价：目标市场的定价（参考竞品价格带）
- 采购成本：1688/工厂报价 + 包装
- 平台佣金：平台当期费率 × 售价
- 物流成本：头程 + 尾程（找货代要实价）
- 退货损耗：售价 × 类目退货率 × 0.5（退回来的货按半价残值算）

示例（售价 24.99）：24.99 − 7.5 − 3.75 − 6.2 − 0.8 = 6.74，毛利率 27% → 利润空间 3 分。

## 5. 决策阈值

```
加权总分 = Σ(维度分 × 权重)
```

| 总分 | 结论 | 动作 |
|---|---|---|
| ≥4.0 | Go（推进） | 小批量试销（首单 ≤300 件）验证 |
| 3.0~4.0 | Caution（谨慎） | 必须写清扣分项的补救方案再推进 |
| <3.0 | No-Go（放弃） | 存档，换候选 |

**两条熔断**：合规风险=1 → 直接 No-Go；毛利率<20% → 直接 No-Go。总分再高也不许绕过。

## 6. pick.json 格式

```json
{
  "product_name": "可叠加厨房收纳盒",
  "target_market": "Amazon 美国站",
  "category": "厨房收纳",
  "dimensions": {"市场需求": 4, "竞争烈度": 3, "利润空间": 4, "物流适配": 4, "合规风险": 5},
  "price_calc": {"售价": 24.99, "采购成本": 7.5, "平台佣金": 3.75, "物流成本": 6.2, "退货损耗": 0.8},
  "logistics": {"头程运费": 6.2, "尾程运费": 3.8, "配送时效": "18-25天"},
  "note": "分数依据写这里，如 Top10 竞品评价数区间"
}
```

**审计对应**：5 维缺一（SCORE-DIM-001）、分数非法（SCORE-DIM-001）、利润公式缺项（PROFIT-001）、物流缺标注（LOGISTICS-001）都是 blocker。

## 7. 反模式（不许这么干）

- ❌ 5 个维度没打完就写"建议做"（缺维度不许出报告）
- ❌ 竞争烈度按正向打分（竞争越大分越高——反了）
- ❌ 利润测算不含退货损耗（退货是跨境的隐形杀手）
- ❌ 用"感觉"打分：每维分数必须写一句话依据
- ❌ 熔断项（合规=1/毛利<20%）被总分"平均掉"
- ❌ 给出"保证爆款/必赚"结论（红线：只给 Go/Caution/No-Go + 依据）

## 8. 常见问题

- **Q：用户没有平台后台数据，怎么打分？** A：先按"用户描述+公开信息"打初版，每维标注"待核实"；数据回来后再打终版。初版不许出 Go 结论，最高给 Caution。
- **Q：三个候选产品怎么比？** A：同一张表、同一套标尺打完，按加权总分排序；分差 <0.3 看"合规风险"和"利润空间"谁高。
- **Q：权重能不能调？** A：能，但要说清理由。资金紧张的用户可把利润空间提到 30%；物流资源弱的可把物流适配提到 20%。调完权重重新算总分。
- **Q：季节性产品怎么打"市场需求"？** A：按"旺季分"打，但必须在结论里写清"窗口期只剩 X 个月，备货周期 Y 天，来得及吗"。
- **Q：用户说"我就想卖这个，分数低也做"？** A：把报告给他，明确写"No-Go 及原因"，让他签字画押式确认"已知风险仍要推进"。不许为了迎合改分数。

## 9. 自检与反馈

**质检门**：
- [] 5 维齐全，分数 1~5，每维有一句话依据？
- [] 利润公式 5 项齐全，毛利率算出来了？
- [] 物流三项标注齐全（头程/尾程/时效）？
- [] 熔断检查做了（合规=1？毛利<20%？）？
- [] 审计脚本 6 条规则全过（`pick_audit.py` exit==0）？
- [] 报告含数据声明，无承诺表述？

**标准冒烟用例**：`fixtures/pick-bad/` 应命中 6 条规则全部（exit!=0）；`fixtures/pick-good/` 零 blocker（exit==0）。
